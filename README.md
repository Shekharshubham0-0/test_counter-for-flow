# 🧮 Counter Smart Contract

A simple blockchain-based smart contract that allows users to **increment** or **decrement** a stored number on the Ethereum network.  
It serves as an introductory example for learning how to manage state and interact with smart contracts.

---

## 🚀 Features
- Increment and decrement a stored counter value  
- View the current count anytime  
- State data is permanently stored on-chain  
- Includes logic to prevent negative counts  

---

## 🧠 Key Concepts
This project helps beginners understand the following Solidity fundamentals:
- **State Variables:** How data is stored persistently on the blockchain  
- **Functions:** How to modify and retrieve data  
- **Require Statements:** How to ensure logical and safe operations  
- **User Interaction:** How users can trigger transactions to change state  

---

## ⚙️ Deployment (Using Remix IDE)
1. Open [Remix IDE](https://remix.ethereum.org)  
2. Create a new file named **Counter.sol**  
3. Paste the contract code  
4. Compile using **Solidity compiler v0.8.0 or higher**  
5. Go to the **Deploy & Run Transactions** tab  
6. Choose an environment (e.g., Remix VM, Injected Provider, or Custom Network)  
7. Click **Deploy**  
8. Interact with the contract using the Remix interface

## 🧪 How to Interact
After deployment, you can:
- **Increment** → Increases the counter by one  
- **Decrement** → Decreases the counter by one (if greater than zero)  
- **Get Count** → Returns the current stored value
